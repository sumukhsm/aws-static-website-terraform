# AWS Secure Static Website Hosting using Terraform

## Project Overview
This project demonstrates secure static website hosting using Amazon S3, CloudFront CDN, IAM policies, and Terraform Infrastructure as Code (IaC).

The infrastructure was deployed using Terraform and designed following AWS cloud best practices for scalability, security, and global content delivery.

---

## Technologies Used
- AWS S3
- AWS CloudFront
- AWS IAM
- Terraform
- HTML/CSS

---

## Features
- Static website hosting using Amazon S3
- Global content delivery using CloudFront CDN
- Infrastructure as Code (IaC) using Terraform
- Secure bucket access configuration
- Automated deployment of website files
- Lightweight serverless architecture

---

## Architecture Components
- S3 Bucket
- CloudFront Distribution
- IAM Bucket Policy
- Static HTML Website
- Terraform Configuration Files

---

## Deployment Steps
1. Configure AWS CLI
2. Initialize Terraform using terraform init
3. Validate Terraform configuration
4. Run terraform plan
5. Deploy infrastructure using terraform apply
6. Access website using CloudFront URL
7. Destroy infrastructure using terraform destroy
